# PARKST 차트 학습실

워뇨띠의 공개 과거 체결 기록과 Binance 과거 가격 봉을 겹쳐 복기하고, 블라인드 판단 비교 테스트를 실행하는 정적 웹앱입니다.

- [매매기록](AOA_%EB%A7%A4%EB%A7%A4%EC%B0%A8%ED%8A%B8.html)
- [블라인드 매매테스트](trainer.html)

티스토리 [parkst.tistory.com](https://parkst.tistory.com/)에서 사용합니다. TradingView, Binance, BitMEX 또는 기록 당사자의 공식 서비스가 아닙니다. 봉 가격과 체결 상품은 다르며 손익 계산이나 투자 자문을 제공하지 않습니다. 차트 라이브러리의 라이선스와 고지는 동봉 파일을 참조하세요.
